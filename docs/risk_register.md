# Risk Register (`docs/risk_register.md`)

Tracks statistical, numerical, data, and operational risks across the lifecycle of `quant-lab`. Reviewed monthly and at every phase gate.

| ID | Category | Risk Description | Severity | Likelihood | Mitigation Strategy | Status |
|---|---|---|---|---|---|---|
| **R-01** | Statistical | **Multiple-Testing Overfitting:** Repeatedly evaluating strategies on the same US equity historical window inflates false discoveries. | High | High | Mandatory two-file experiment ledger (`ledger.jsonl` + `trial_returns.parquet`); Deflated Sharpe Ratio (DSR) using effective trial count $\hat{N}_{\text{eff}}$; CSCV/PBO; sealed chronological holdout window. | Active (Phase 1–3) |
| **R-02** | Statistical | **Cross-Sectional & Preprocessor Leakage in CV:** Splitting multi-asset data per ticker or fitting PCA/covariance/scalers before splitting leaks future market returns. | High | Medium | Synchronize Purged K-Fold and CPCV splits across all tickers by timestamp; enforce stateful in-fold `fit`/`transform` protocols; automated leakage test suite (`validation/leakage.py`). | Active (Phase 1–2) |
| **R-03** | Data | **Single-Stock Survivorship Bias:** Selecting today's S&P 500 constituents for a 10-year backtest omits delisted/bankrupt firms. | High | High | Use survivorship-free **Tier 1 (14 US Market & Sector ETFs)** as the primary Phase 2 benchmark; quantify bias on Tier 2 single stocks via PIT constituent lists or UAlberta WRDS/CRSP. | Active (Phase 1–2) |
| **R-04** | Data | **Retroactive Price Mutation (`Adj Close`):** Using vendor backward-adjusted prices changes historical data hashes on every new dividend and breaks option strikes/tick sizes. | Medium | High | Store immutable raw OHLCV + explicit Corporate Actions table (`split_factor`, `div_cash`); derive total-return series deterministically in `data/adjustments.py`. | Active (Phase 1) |
| **R-05** | Data | **Vendor Rate Limits & Feed Traps:** Alpaca free tier defaults to thin IEX volume (~2.5%) for recent bars; Stooq returns HTTP 200 on quota failure; `yfinance` blocks non-browser TLS fingerprints. | Medium | High | Use Tiingo EOD + Alpaca historical with explicit `feed="sip"` and `end <= now - 16min`; validate HTTP response payloads; cache all ingested data locally in Parquet. | Active (Phase 1–2) |
| **R-06** | Hardware | **8 GB Unified Memory Exhaustion on macOS M2:** Eagerly loading large multi-asset panels or running large PyTorch MPS batches causes swap thrashing or OOM crashes. | Medium | Medium | Out-of-core Parquet queries via DuckDB/Polars from Day 1; `quantlab.compute.check_array_memory()` guardrails; `--smoke` flag for M2 verification before 3080 Ti sweeps. | Mitigated in Phase 0 |
| **R-07** | Compliance | **Accidental Credential or Vendor Data Commit in Public Repo:** Pushing API keys or proprietary CSVs/Parquet files violates vendor ToS. | High | Low | `.gitignore` blocks `data/`, `.env`, `*.dbn`; `.pre-commit-config.yaml` enforces secret detection and file-size caps; CI uses synthetic fixtures (`data/synthetic.py`) exclusively. | Mitigated in Phase 0 |
| **R-08** | Numerical | **Ill-Conditioned Covariance & Solver Failure in CVXPY:** Sample covariance matrices with $N \approx T$ are near-singular, causing extreme weights or solver non-convergence. | Medium | Medium | Enforce Ledoit-Wolf/OAS shrinkage and RMT denoising; check condition number $\kappa(\Sigma)$; implement kill-switch fallback to previous weights or `1/N` if solver fails. | Planned (Phase 2) |
